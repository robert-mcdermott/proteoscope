Documentation

How to use Proteoscope, from opening a first structure to statistics on a proteomics report. New here? Start with Getting started.

Quick start

  1. Install Proteoscope with one command.
  2. Run proteoscope in a terminal. It opens in your browser.
  3. Pick one of the Bundled examples, type a PDB ID or UniProt accession in Open structure, or drop your own files on the window.
  4. Double-click a ligand or residue to focus it, and press / to type selections and commands.
