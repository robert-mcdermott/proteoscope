Getting started

Start Proteoscope, find your way around the workspace, and open your first structure.

Start Proteoscope

If you have not installed it yet, see Install. Then, in a terminal:

$ proteoscope

Proteoscope prints a local address, usually http://127.0.0.1:8765, and opens it in your browser. Keep the terminal open while you work, and press Ctrl+C in it to stop Proteoscope. Files and folders named on the command line open directly:

$ proteoscope structure.cif model.pdb.gz af3_output/my_job/

Use Chrome, Edge or Brave, on any desktop system: Proteoscope is developed and tested in these Chromium-based browsers. It needs WebGPU, which Safari provides only from macOS Tahoe (26); Safari on macOS Sequoia or earlier, even Safari 26, does not. Firefox provides it from version 141 on Windows. Browsers without WebGPU get a simplified renderer without surfaces, ambient occlusion or outlines, and say so when Proteoscope starts.

The workspace

  • Top bar: the structure's title, the search box and command line (press /), the renderer badge, and the panel toggles.
  • Left panel, in four tabs:
    • Structure: the structures in the scene, the ranked models of an opened prediction, the entry's metadata (method, resolution, R-free, organism, deposition date), biological assemblies, composition, and sessions.
    • Style: representations, surface, color scheme, sizes, lighting and effects, background, projection and clipping.
    • Analysis: structure comparison, the validation report and density map, interactions, solvent accessibility, the Ramachandran plot, the per-residue profile, PAE with domains, and conservation.
    • Proteomics: search reports, public evidence, sequence properties, UniProt annotations, peptides, sites and variants, cross-links, HDX-MS and custom data.
  • Right panel: the chains (click to show or hide one, double-click to show only that chain), the selection, the interactions of the focused residue, and measurements.
  • Sequence panel: the full sequence of the chosen chain. Residues missing from the model are grey, helices and strands are underlined, and numbering gaps are marked. Click to select, shift-click to add, drag for a range, double-click to focus.
  • Toolbar: reset view, focus, the distance, angle and torsion rulers, spin, image export, full screen and help.
  • Legend: the active color scheme and surface coloring. Click a legend's title to collapse it.

Privacy and network access

Files you open are parsed in your browser and never uploaded. Searches send only what you search for: a query, or a sequence you paste or search with Similar. Remote downloads go through the local Proteoscope server, which only contacts a fixed list of public services:

  • files.rcsb.org, search.rcsb.org, data.rcsb.org and maps.rcsb.org: structures, validation reports, chemical components, searches, entry summaries, and density maps when PDBe's server is unavailable;
  • alphafold.ebi.ac.uk: models, PAE, MSAs and AlphaMissense;
  • rest.uniprot.org: proteins and annotations;
  • www.ebi.ac.uk: PDBe structure lists, 3D-Beacons model lists, the Proteins API for public proteomics evidence, the PDBe volume server and EMDB's map metadata;
  • for models listed by 3D-Beacons, the providers' own servers (SWISS-MODEL, ModelArchive, AlphaFill, PED, SASBDB, isoform.io and RCSB's model server).

Nothing needs an account or API key. Downloads are cached in your user cache folder (for example ~/Library/Caches/proteoscope on macOS) and fetched again after 30 days; searches after a day. The refresh command downloads the active structure again.

Working offline. Start with proteoscope --offline to turn off all network access. Cached entries and the bundled examples still work.
